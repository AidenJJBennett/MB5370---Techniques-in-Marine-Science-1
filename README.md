### --- Welcome to the first module of MB5370 ---
This repository is the first one I have ever made, and is a collection of all my work during Module 1 of MB5370, Introduction to Programming. As data scientists, it is critical that we have a strong foundation in data analysis and organization, skills this module is designed to build. Done in RStudio, we worked on learning how to process large data sets using simple, repeatable steps that are easily remembered and translated into future projects. The later workshops centered around Git integration and a quick introduction to the terminal and console, that will be used more in the later modules. Finally, as AI technology is becoming increasingly prevalent, we as data scientists need to know how to be responsible with its usage, and realize when and where it is appropriate to utilize it in our work. For an experienced data scientist, this module is fairly basic but can still be a great baseline to start with or be a refresher for anyone who hasn't worked with R or programmed in a while.
